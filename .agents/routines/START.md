# /START

Run when starting work on a project for the first time or after a long pause.

## Protocol

1. Check if the `.agents/` scaffold exists. If not, copy it from the base template repository.
2. Read `about.md` — understand current architecture.
3. Read `steps.md` — understand pending work and what's done.
4. Skim `inbox.md` for unplanned items.
5. Report current state: what's done, what's pending, what's blocked.
